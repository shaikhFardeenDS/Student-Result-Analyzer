# Student Result Analyzer 📊

A beginner-friendly Python project that analyzes student marks and prints a clear result report.

## Features

- Calculates each student's average marks
- Assigns grades based on average marks
- Displays a formatted table of results
- Calculates the class average
- Identifies the highest-scoring student

## Built with

- Python 3
- Built-in functions and data structures
- Functions, loops, conditional statements, and `max()`

## How to run

1. Install Python 3 if you do not already have it.
2. Download or clone this repository.
3. Open a terminal in the project folder.
4. Run:

   ```bash
   python main.py
   ```

   On some Windows installations, use `py main.py` instead.

## Customize it

Edit the `students` list in `main.py` to add your own sample students and marks. Each student should have a name and a list of three marks.

## Learning goals

This project is useful practice for Python lists, dictionaries, functions, loops, conditionals, and basic data analysis.
